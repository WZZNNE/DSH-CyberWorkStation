凭据中心 // CREDENTIALS

dsh 本体与所有插件用到的 API 凭据引用都在这里:是否已配置、存在哪里、绑定在哪些功能上;起别名、写备注、新增/替换/删除密钥。密钥值只经过 dsh 的凭据服务(装了凭据钥匙串插件就是 Windows 凭据管理器),从不写进普通文件;dsh 需在运行。

模型清单
从 openrouter.ai 拉取最新模型清单写进 OpenRouter 路由(新模型入表、名称/上下文/输出上限刷新、可推理模型写入思考强度档位);手改过的字段不动。
dsh 默认模型
新会话默认使用的路由和模型(settings 命名空间 agent-default-model);dsh 设置 → 凭据中心 里写的是同一处。

记忆与上下文 // MEMORY & CONTEXT

左边的「会话上下文」能看每个会话当前的压缩摘要并直接改;「长期记忆」是跨会话的事实/笔记/摘要,会在相关时作为单独上下文行注入。两者都由 dsh-memory-lite 插件在本体里完成,dsh 需在运行。
点一个会话看它的上下文占用、当前生效的压缩摘要与压缩历史;摘要可改后保存,下一次请求起模型就按改后的摘要继续(写成一次真实的压缩记录,原文仍在日志里)。
没有会话
← 选一个会话
摘要来自压缩,事实由模型每隔几轮抽取,笔记由你或模型(memory_note)写入;钉住的条目在新会话第一轮优先注入(受注入预算限制),其余按相关度。
新增一条
默认:自动存压缩摘要、每 8 轮抽取事实、相关时注入、开放两个记忆工具;向量召回可选(LM Studio / Ollama 的 /v1/embeddings),不开也能用词法召回。
