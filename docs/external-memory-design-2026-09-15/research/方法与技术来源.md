# 调研方法 证据等级与技术来源

## 1 调研范围

检索截止日为 2026 年 9 月 15 日。调查围绕用户提出的外部项目记忆库，覆盖外部记忆系统、写入与演化、切块和检索、工作经验记忆、多 agent 协作与撤销、模型内部记忆对照、公共评测、接入协议和存储基座。

“所有相关”在开放且持续变化的研究领域不能被一次调查证明穷尽。本包是有明确范围的定向全景调查，不是预注册的系统综述、逐仓库运行审计或法律新颖性意见。主索引逐项标明证据深度，避免将条目数量误当验证强度。

## 2 检索与筛选流程

1. 以 MemGPT/Letta、Mem0、Graphiti、A-MEM 为种子，扩展到本地记忆服务、可编辑文件记忆、记忆框架和存储组件。
2. 以 LongMemEval/LoCoMo 为评测种子，扩展到隐含查询、多会话任务、生命周期和撤销研究。
3. 以候选设计主张反向检索：temporal memory、revocation enforcement、write-back resurrection、multi-agent consistency、memory lifecycle、project scope、editable memory。
4. 优先查看论文原文、arXiv 版本元数据、官方仓库、根 LICENSE 和官方文档；对主要候选保存固定提交或当前分支证据。
5. 对同名、改名、SDK/服务端、历史实现和托管专有能力进行拆分。
6. 检查当前工作区已有实现，用源码行号说明复用范围和集成缺口。
7. 将设计判断与已有证据区分，再通过参考模型检查可确定的核心状态规则。

代表性查询包括 agent memory temporal updates、LLM memory revocation deletion resurrection provenance、multi-agent authorization revocation、constraint lifecycle benchmark、context-driven memory retrieval、SQLite WAL network filesystem、MCP authorization。详细项目与论文索引保留每条来源链接；本次不宣称逐条搜索结果均已保留或构成完整 PRISMA 流程。

## 3 证据等级

| 等级 | 本包含义 | 不能推出的结论 |
|---|---|---|
| 资料级 | 官方 README、文档、摘要与元数据核对 | 功能已正确实现或适合生产 |
| 正文级 | 阅读论文注明的关键章节 | 全文逐页审计或独立复现 |
| 源码级 | 当前 DSH 指定代码路径与行号核对 | 所有运行分支已测或真实用户数据无误 |
| 参考验证级 | 本包有限模型在记录环境中通过指定测试 | 完整应用、模型质量、断电可靠性或云端规模已验证 |

未核实某项能力，不等于证明项目没有该能力。README 的能力主张在对照矩阵中用“文档描述/待实测”表达。许可分类仅覆盖指定版本根许可，不替代依赖、权重、资产和托管服务条款的完整评估。
