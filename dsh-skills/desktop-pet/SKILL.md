# 桌宠制作工艺

dsh 的桌宠由 `dsh-desktop-pet` 插件驱动,配置全部在 **设置 → 桌宠** 里,也可以用 HTTP 路由写(见最后一节)。
你的任务是陪用户把一只宠物做出来:**先问,再设计,再出素材,最后落地**。不要一上来就写一大段人设。

## 一、先问清楚(缺哪条就问哪条,别猜)

1. **形象**:是什么(猫/史莱姆/机器人/二次元少女/公司吉祥物…)?体型比例?主色?
2. **性格**:三个形容词就够(毒舌、慵懒、话痨…);说话长度(一句话 / 两三句);称呼(主人/你/名字)。
3. **场景**:陪写代码?催进度?纯闲聊?要不要主动搭话、多久一次(低 30-60 / 中 15-30 / 高 5-15 / 繁 1-5 分钟)。
4. **权限**:要不要让它看屏幕、动鼠标键盘。默认给「每次询问」,别默认「完全允许」。
5. **语音**:要不要念出来(要接 TTS),要不要一直开着听(要接 STT)。
6. **素材**:用户自己有图,还是要现场生成。

## 二、写人格提示词(填进「人格设定」)

结构固定,好用且省 token:

```
你是「<名字>」,<一句话身份>。
说话风格:<语气><句长>,自称<自称>,叫用户<称呼>。
你喜欢<两三件事>,讨厌<一件事>。
边界:不知道就说不知道;不编造你没看到的屏幕内容;主人在忙的时候少说话。
```

要点:

- **别写小说**。人设越长,小模型越容易跑偏,150 字以内最稳。
- 想要「知道自己长什么样」,把外观写进 **外观描述** 那一栏,不要塞进人格里 —— 生图时插件会自动把这段带上,形象才不会漂。
- 世界书(设定集)放**具体事实**:主人的猫叫团团、项目叫什么、口头禅是什么。人格放**风格**。

## 三、素材清单(用户问「我要准备什么图」时照抄这一段)

桌宠窗口按 **一个表情 = 一张图** 工作,一张图配一个 CSS 动作就能跑;要真动起来就上序列帧(8-24 帧,见第九节)。

| 用途 | 建议规格 | 说明 |
|---|---|---|
| 默认站立 | PNG,透明背景,512×512 或 512×640 | 必需。窗口默认 220×260,给两倍图更清晰 |
| 常用表情 | 同上,建议 4-8 张 | happy / sad / angry / surprised / sleepy / thinking / working / cheer |
| 动作 | 同上 | wave(打招呼)、eat、jump、type(敲键盘) |
| 序列帧 | 每个表情 8-24 张,同一构图 | 想要真动画就给这个,帧数和帧率在面板里填 |
| 图标 | 可选,ico | 托盘图标 |

规格要求:

- **背景必须透明**(PNG alpha)。桌面精灵是逐像素透明窗口,柔边会跟桌面混在一起;不透明的图会显示成一个方块。
- 主体尽量占满画布、留 8-16px 边距;所有表情**同一构图、同一比例**,切换时才不会跳。
- 单张 ≤ 2 MB;序列帧每个表情 ≤ 24 张。
- 命名用英文:`happy.png`、`sleepy.png`,和「表情/动作」表里的**文件名**一致。

上传方式:设置 → 桌宠 → 表情/动作 → **上传素材**(图片进 `$DSH_HOME/pets/<id>/assets/`;`.txt/.md/.json/.csv` 会自动变成世界书条目)。

## 四、画图提示词(接了图像 API 就能直接出图)

先确认 **设置 → 多媒体 API → 生图** 已启用,然后你可以直接调用 `generate_image` 工具出图,并把文件路径告诉用户。

一致性的关键是**同一段角色描述 + 只换表情词**:

```
<角色描述:物种、体型、主色、服饰、标志性特征>,
<表情词>,
full body, centered, transparent background, game asset, clean vector-ish shading,
soft rim light, no text, no watermark
```

表情词参考:`smiling happily, eyes closed` / `pouting, arms crossed` / `sleepy, half-closed eyes, small zzz` /
`surprised, wide eyes, mouth open` / `focused, typing on a tiny keyboard` / `cheering, both arms up`。

批量出图时:**先出默认站立**,让用户确认形象,再用同一段角色描述出其余表情。每张出完就报文件路径,别一次憋十张。

透明背景:很多接口不直接给 alpha。可行做法——提示词里写 `plain flat #FF00FF background`(纯洋红),再让用户用任意抠图工具去底;或者选支持透明的模型(如 gpt-image 系列的 `background: transparent` 参数,可写进「多媒体 API → 生图」的 extra 里)。

## 五、落地(把设计写进插件)

引导用户在 **设置 → 桌宠** 里填:名字 → 人格设定 → 外观描述 → 桌宠自己的 API(接口地址/模型/Key)→ 权限 → 主动搭话频率 → 表情表 → 保存。

要你代劳时,可以直接打这些本地路由(同源 JSON POST):

| 路由 | 作用 |
|---|---|
| `POST /dsh-desktop-pet/pet` | 写一只宠物:`{ id, pet: {...}, activate: true }`。**人设/外观/表情说明会原样进系统提示词**;由程序写入的人设,会让这只宠物之后每一轮都按「读到过外面的东西」算(重启也不会清除,要在面板里保存一次才算主人认可)。如果这只宠物被设成了「人设也影响主助手」,程序写人设会把它改回只影响宠物自己。写之前先跟主人确认文字 |
| `POST /dsh-desktop-pet/lore` | 往世界书里**追加**条目:`{ pet, entries: [{key, content}] }`(同 key 覆盖;程序不能清空或整体替换,那只能在面板里做) |
| `POST /dsh-desktop-pet/asset` | 上传素材:`{ pet, name, base64 }` |
| `POST /dsh-desktop-pet/say` | 替用户说一句,拿到回复(**不是主人自己打的字**:这一轮按「读到过外面的东西」算,操作电脑会弹确认) |
| `POST /dsh-desktop-pet/proactive/now` | 让它现在主动说一句 |
| `POST /dsh-desktop-pet/schedule` | 定一个提醒;由程序定的会被标记,到点触发时操作电脑仍会弹确认 |
| `POST /dsh-desktop-pet/window/start` | 开桌面窗口:`{ pet, variant }`(`winforms` 或 `webview`) |

宠物的模型建议选**便宜的多模态小模型**(它要看截图),和主助手的模型分开——桌宠说话很频繁,别拿贵模型陪聊。

## 六、关于权限的一句话

就算主人给了「完全允许」,只要这段对话里出现过**不是主人自己打的字**(截图、搜索结果、上传的素材、主人画像、当前任务信息、桌宠自己定的提醒、以及由程序而不是面板发来的 `/say`、提醒和人设),操作电脑仍然会弹一次确认。这是有意的:桌宠读到的东西不能直接变成鼠标动作。想让它安静地干活,就开一个新对话再说。

## 七、语气标记(配了 Fish Audio 的话)

Fish Audio 的 S2 系列(`s2-pro`/`s2.1-pro`/`drama3`)认识写在句子里的方括号标记,会照着演,标记本身不会被念出来 —— 见 <https://docs.fish.audio/api-reference/emotion-reference>。

**不用你做任何事**:只要「设置 → 多媒体 API → 语音合成」选的是 `fish-audio`,桌宠的系统提示词里会自动多出一段语气标记词表,它自己就会写 `[chuckling]`、`[emphasis]`、`[压低嗓子坏笑]` 这类标记;这些标记只送去合成,不会出现在气泡和对话记录里。

你要做的只是:

1. 把人设写得有情绪(「爱吹牛」「笑起来没心没肺」),模型才用得上这些标记;
2. 如果主人换了别家语音,这段词表会自动消失 —— 别在人设里硬写标记规则,那会让别家的语音把方括号念出来。

标记的分类(情绪 / 语气 / 声音效果 / 特效)和完整列表以官方那一页为准,S2 系列还接受自然语言描述,不限于固定词表。

## 八、序列帧动画(要「丝滑」就走这条)

一个表情可以是一张图,也可以是一串图。面板里「表情/动作」那行的**帧数**填几,它就有几帧;**帧率**是每秒播几帧。第 1 帧就是「图片文件名」本身,其余的按两位数排在旁边:

```
assets/rest.png      第 1 帧
assets/rest-02.png   第 2 帧
assets/rest-16.png   第 16 帧
```

三个窗口都会播,而且是**来回播**(正着走完再倒着走回来),所以首尾对不上的一串图也能无缝循环;想只正着播就把这个表情的 `loop` 设成 `forward`。帧数填 1 就还是一张静图配 CSS 动作。

**帧从哪儿来。** 自己画当然行;接了图像+视频 API 的话,按这条流水线生成:

1. 先用图像模型画一张**平铺洋红底**的立绘(别让它画透明背景,模型会把棋盘格当图案画上去)。
2. 把这张图垫到 16:9 的洋红画布中间(人物只占约 2/3 高),留出边距——视频模型爱推镜头,留了边才不会把底色吃光。
3. `POST /dsh-media-lab/generate`,`{"kind":"video","image":"<立绘的绝对路径>","prompt":"<他做什么>+锁死机位+纯洋红背景"}`,拿回一段 mp4。
4. ffmpeg 只抽**前两秒**(镜头还没飘的那段)的 16 帧。
5. `SpriteCutout.exe` 先用 `--bounds` 量每一帧,取并集,再用 `--crop=x,y,w,h` 统一裁——**整串必须用同一个矩形**,否则播起来人物会一跳一跳。
6. 逐帧走 `/dsh-desktop-pet/asset` 传上去,第 1 帧用表情本名,其余带 `-02`…`-16`。

## 九、外观(气泡长什么样)——原来的皮肤那一套现在归桌宠自己管

设置 → 桌宠 → **外观(气泡样式)**。这一套值三个窗口共用:桌面精灵的气泡和输入框、桌宠页、dsh 里的浮窗,所以一只桌宠在哪儿都长一个样,两只桌宠可以完全不一样。

| 项 | 干什么用 | 说明 |
|---|---|---|
| 气泡底色 / 文字颜色 | 主色调 | `#rrggbb`,填别的会被忽略并退回默认值 |
| 强调色 | **主人说的那一侧**的气泡 | 会跟底色混一点,不是纯色块 |
| 透明度 | 0.25–1 | 和「毛玻璃」两个合起来才是「玻璃」;单调透明度只是变淡 |
| 毛玻璃 | 0–40 | 网页端走 `backdrop-filter`,桌面精灵走 Windows 自己的亚克力;调成 0 就是不磨砂 |
| 圆角 | 0–28 | 消息来的那一侧留一个直角,像正经聊天软件 |
| 字号 | 10–20 | 桌面精灵会换算成磅值 |

面板里带一块**棋盘格预览**——你调的本来就是「桌面透出来多少」,平铺在纯色上看不出来。上面还有三个预设:玻璃 / 实心 / 暖纸,点一下就是一整套,再自己微调。

想让某只桌宠用另一套配色,就改那只的这一栏——它存在桌宠自己身上(`theme`),不是全局皮肤。

**界面素材是一个皮肤库**:三张素材(气泡底板/输入框/发送键)可以逐张「导入」自己画的 PNG,凑齐后「存为一套」起个名;库里的任何一套可以「应用」到任何桌宠(文件是复制过去的,删库里的套装不影响正在穿的桌宠)。「用生图模型生成」只是凑素材的一种办法。

**想让生图模型画**:点「用生图模型生成(备选)」。它会生成三张——气泡底板、输入框、发送键——抠掉底色存进桌宠素材里,然后三个界面都用**九宫格**把它们撑开(四角原样、四边单向拉、中间双向拉),所以一张图能包住任意长度的一句话。要点:

- **先让 API 直接出透明底**:`{"kind":"image","background":"transparent","format":"png"}`(OpenRouter 文档写明 transparent 必须配 png/webp)。这条走通就不用抠图了。
- 供应商不认这个参数才退回抠图,用 `--key=auto`(按四角取底色)——生图模型经常不按你说的洋红来,给你一片暗紫。
- 让它画**空的**:不要文字、不要图标、不要箭头。上面要放的字是运行时才有的。
- **输入框在哪套皮肤下都是不透明的**。半透明可以放在字的后面,不能放在字的下面——打进去的字看不清,这套 UI 就是废的。

## 十、桌宠多大

桌面精灵可以拖右下角自由缩放(90–1400 px,光标移上去会显出手柄),也可以 Ctrl+滚轮,或者面板里拉滑块。两条边永远一起动:立绘只有一个比例,拉成别的形状一眼就假。改完的大小会记回配置里。


## 十一、常见问题

- **桌面窗口一闪就没了**:先确认 dsh 在跑(桌宠窗口靠 `127.0.0.1:3080` 取内容);再看 `$DSH_HOME/pets/_host/PetHost.exe` 是否编译成功(需要 Windows 自带的 .NET Framework 4 编译器)。
- **窗口是黑底不是透明**:图没有 alpha 通道,或用了 JPG。
- **表情不切换**:模型没写 `[expr:名字]` 标记,或标记里的名字和表情表对不上;把可用表情写进人格提示词里提醒它。
- **它说看不到屏幕**:权限是「不允许」;改成「每次询问」后,它申请时会在 dsh 里弹出同意/拒绝。
- **一直不说话**:主动搭话没开,或者「主人忙的时候别打扰」正好在生效。
